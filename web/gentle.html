          Details
          

            
The file is split into small pieces so it can be stored on Ethereum. Once every piece is stored, the photograph can be registered. Registering links those pieces into one finished photograph the factory can show. Pieces are bound to the wallet that stored them, so another account cannot register them. Until registration, the pieces exist on-chain but are not yet a complete plate. Register after storing so this wallet finishes the photograph. Clearing site data does not move the pieces; reconnect with the same wallet to resume.

            
Two ways to upload

            
Choose Upload Manually or Upload with Agent above.

            
    
              
  • Recommended Manual Path: “Store every piece” sends the pieces of the photograph that are not stored yet, in groups. Each group is as many pieces as fit in one block, and the wallet confirms once for each group. Pieces this account already stored are skipped.
    • 
              
  • Backup Manual Path: “Store piece” sends the next piece that is not stored yet, and the wallet confirms once.
    • 
              
  • Agent / script: This route uploads groups of pieces without a wallet confirmation for each group. The keystore on your computer signs them instead. Copy agent prompt downloads the photograph named in IMAGE, including a packed JPEG, and the thumbnail. The prompt tells the agent to check the photograph before anything is sent. That check does not unlock the keystore. When the check matches, the send asks for the password once in the terminal. If the agent cannot take that password, it gives you one command to copy into a new terminal window. Type the password there once. That send stores every remaining group and registers the photograph. If some pieces are already stored, the agent starts at the first missing one and does not send those again.
